Lesson 2.8

Introduction to random variables and probability distributions

A random variable is a numerical outcome of a random process. A discrete random variable takes a countable list of separate values (counts such as 0, 1, 2, …). A continuous random variable can take any value in an interval (times, heights, weights).

The probability distribution of a discrete random variable X lists every possible value x with its probability P(X = x). It can be shown as a table, a formula, or a probability histogram.

Two requirements (1) 0 ≤ P(x) ≤ 1 for every value   (2) the probabilities add to exactly 1: ΣP(x) = 1.
  • Complement rule: P(X ≥ 3) = 1 − P(X ≤ 2) (for integer values).
  • Cumulative distribution: F(x) = P(X ≤ x) adds up the probabilities from the smallest value to x. Then P(X = x) = F(x) − F(x − 1).
  • Estimating a distribution: from long-run relative frequencies in data or a simulation (number of trials with that outcome ÷ total trials).

Lesson 2.9

Parameters of random variables

A parameter describes a population or probability distribution. The center and spread of a discrete random variable are:

μX = E(X) = Σ xi · P(xi)     σX = √( Σ (xi − μX)² · P(xi) )
AP-style interpretations (always in context, with units) Mean: "If this random process were repeated a very large number of times, the average value of X would be about μ (units)."
Standard deviation: "The values of X typically vary by about σ (units) from the mean of μ (units)."
  • The expected value does not have to be a possible value of X (an average of 1.7 children is fine).
  • It describes the long run, not a single repetition.
  • The variance is σ²; take its square root to get σ.

Lesson 2.10

The binomial distribution

A binomial random variable X counts the number of successes in n trials. Justify it with BINS:

  • Binary — each trial is a success or a failure.
  • Independent — trials do not affect each other (when sampling without replacement, check the 10 % condition: n ≤ 10 % of the population).
  • Number of trials is fixed in advance.
  • Same probability p of success on every trial.
P(X = k) = n!k!(n − k)! pk(1 − p)n−k
μX = np     σX = √(np(1 − p))
Calculatorbinompdf(n, p, k) = P(X = k)  ·  binomcdf(n, p, k) = P(X ≤ k). For "at least": P(X ≥ k) = 1 − binomcdf(n, p, k − 1).

Lesson 2.11

The normal distribution

A normal distribution N(μ, σ) is a symmetric, unimodal, bell-shaped density curve described by its mean μ (center) and standard deviation σ (spread). It is the model for a continuous random variable: probabilities are areas under the curve (total area = 1), and P(X = a) = 0 for any single value, so < and ≤ give the same probability.

Empirical rule (68–95–99.7)About 68 % of values lie within 1σ of μ, 95 % within 2σ, and 99.7 % within 3σ.
z-score
z = x − μσ
Number of standard deviations x is above (+) or below (−) the mean. Use z-scores to compare values from different distributions.
Calculator normalcdf(lower, upper, μ, σ) gives an area (use ±1E99 for "no bound"). invNorm(area, μ, σ) gives the value with that area to its left (a percentile).

Lesson 2.12

Sampling distributions and the Central Limit Theorem

A statistic (like the sample mean x) changes from sample to sample. Its sampling distribution is the distribution of values the statistic takes over all possible random samples of the same size from the same population. We can simulate it: take many random samples, compute the statistic for each, and graph the results.

Central Limit Theorem (CLT) For a random sample of size n from a population with mean μ and standard deviation σ, the sampling distribution of x becomes approximately normal as n gets large (rule of thumb: n ≥ 30), whatever the shape of the population. Its center is μ and its spread is σ/√n.
  • If the population is already normal, the sampling distribution of x is normal for any n.
  • Larger samples → less variability in x (σ/√n shrinks), but the same center.
  • Conditions: random sample; if sampling without replacement, n ≤ 10 % of the population.
