Hypothesis test for a mean (σ unknown): the t test

t = x̄ − μ0s/√n df = n − 1Compare with the t distribution; use the same decision rule: p ≤ α → reject H₀

Conditions: random sample, independent observations, and a roughly normal population or a large sample (n ≥ 30; with small n check the histogram for strong skew or outliers).

Worked example · average handling time

A manual claims that the mean handling time is 50 minutes. A random sample of n = 36 cases has x̄ = 47.2 and s = 8. Test H₀: μ = 50 versus Hₐ: μ ≠ 50 at α = 0.05.

  1. H₀: μ = 50; Hₐ: μ ≠ 50; α = 0.05.
  2. SE = 8/√36 = 1.333; t = (47.2 − 50)/1.333 = -2.10; df = 35.
  3. Two-sided p = 0.0430 (Excel: =T.DIST.2T(2.1, 35)).
  4. 0.0430 < 0.05 → reject H₀.
Answer: There is sufficient evidence (t = -2.10, p = 0.043) that the mean handling time differs from 50 minutes; the sample suggests it is shorter.
Excel

Tail areas: =T.DIST.RT(t, df) (right), =T.DIST.2T(ABS(t), df) (two-sided), =T.DIST(t, df, TRUE) (left). Critical value: =T.INV.2T(α, df) or =T.INV(1-α, df). With raw data: Data Analysis ToolPak, or compute x̄ with AVERAGE and s with STDEV.S.

Hypothesis test for a proportion: the z test

z = p − p0√[p0(1 − p0)/n]Use p₀ (the value in H₀) in the standard error. Conditions: np₀ ≥ 10 and n(1 − p₀) ≥ 10

Worked example · defect rate

A supplier says at most 10 % of items are defective. A random sample of 400 items contains 52 defectives. Is the defect rate higher than 10 % (α = 0.05)?

  1. H₀: p = 0.10; Hₐ: p > 0.10 (right-tailed).
  2. p̂ = 52/400 = 0.13. Conditions: np₀ = 40 and n(1 − p₀) = 360, both ≥ 10.
  3. SE₀ = √(0.1 × 0.9/400) = 0.0150; z = 0.03/0.0150 = 2.00.
  4. p = P(Z ≥ 2.00) = 0.0228 ≤ 0.05 → reject H₀.
Answer: There is sufficient evidence (z = 2.00, p = 0.023) that the defect rate exceeds 10 %. (A two-sided test would give p = 0.046, still below 0.05.)

Type I and Type II errors and power

Decisions and reality
H₀ is actually trueH₀ is actually false
Reject H₀Type I error (false alarm), probability αCorrect: power = 1 − β
Fail to reject H₀Correct, probability 1 − αType II error (miss), probability β
The costs differ: choose α accordingly
ContextType I errorType II error
Quality control (H₀: lot acceptable)Reject a good lot: waste, delayShip a bad lot: returns, reputation
Drug or product launch (H₀: no improvement)Launch something that does not helpMiss a real improvement
Fraud screening (H₀: transaction is genuine)Block a genuine customerLet fraud through

Power = 1 − β is the probability of detecting a real effect. It increases when: the sample size n increases, the true effect is larger, the population variability is smaller, or α is larger. For a fixed n, lowering α raises β.

What to try
  1. Set n = 25, d = 0.5: power ≈ 80 %.
  2. Lower α from 0.05 to 0.01 (n fixed): β grows.
  3. Raise n to 100: both errors are small. Only a larger sample improves both.

Confidence intervals and tests

A two-sided test at level α rejects H₀: μ = μ₀ exactly when μ₀ is outside the (1 − α) confidence interval. The interval is more informative: it shows which values of μ are plausible and how large the effect might be.

Which tool?
If you need…Use
A decision about a specific claimHypothesis test (p-value)
The size of the effectConfidence interval
BothReport the estimate, the interval and the p-value

From p-value to business decision

  • Combine statistical evidence with costs and benefits: a significant but tiny improvement may not justify a new process.
  • Report the effect size and a confidence interval, not only “p < 0.05”.
  • State assumptions and limitations (sampling method, data quality).
  • Beware of multiple testing: if you test 20 true null hypotheses at α = 0.05, expect about one false positive.

Common mistakes

  • Using p̂ instead of p₀ in the standard error of a proportion test (a confidence interval does use p̂).
  • Using z instead of t when σ is unknown and n is small.
  • Forgetting df = n − 1.
  • Saying “the probability of a Type I error is the p-value” (it is α).
  • Concluding “no effect” from a non-significant result with a small sample: low power may be the reason.
  • Ignoring the cost of each error when choosing α.
