1. Solving multi-step equations and equations with variables on both sides

You should be able to… Distribute, combine like terms, solve with variables on both sides, and check by substitution.

Key ideas

  1. Distribute any number outside parentheses to every term inside: a(b + c) = ab + ac.
  2. Combine like terms on each side separately (x-terms with x-terms, numbers with numbers).
  3. Get the variable terms on one side by adding or subtracting the smaller x-term from both sides.
  4. Undo addition/subtraction, then undo multiplication/division (do the same to both sides).
  5. Check by substituting the answer into the original equation.
Fractions and decimals

Clear them first: multiply every term by the LCD (for fractions) or by 10, 100… (for decimals). Then solve as usual.

Three possible outcomes
After simplifying you get…Meaning
x = 4 (a single number)one solution
5 = −7 (a false statement)no solution
6 = 6 (a true statement)infinitely many solutions (identity)

Worked example · variables on both sides

Solve 3(2x − 4) + 5 = 2x + 9.

  1. Distribute: 6x − 12 + 5 = 2x + 9.
  2. Combine like terms: 6x − 7 = 2x + 9.
  3. Subtract 2x: 4x − 7 = 9.
  4. Add 7: 4x = 16.
  5. Divide by 4: x = 4.
  6. Check: 3(8 − 4) + 5 = 17 and 2(4) + 9 = 17 ✓.
Answer: x = 4
Common mistakes
  • Distributing to only the first term: 2(x + 3) ≠ 2x + 3.
  • Sign errors with negatives: −2(3x − 5) = −6x + 10.
  • Adding to one side only: every step must be done to both sides.
  • Not checking: a quick substitution catches most errors.

2. Constant rate of change and linear relationships

You should be able to… Find rates of change; tell proportional, nonproportional linear and nonlinear apart in tables, graphs, equations and words.

Key ideas

rate of change = change in ychange in x = y₂ − y₁x₂ − x₁
Telling relationships apart
TypeRate of changeEquationGraphTable
Proportionalconstanty = kxstraight line through (0, 0)y/x is always the same
Linear, nonproportionalconstanty = mx + b, b ≠ 0straight line not through (0, 0)constant differences, y ≠ 0 at x = 0
Nonlinearchangesx², 1/x, …curvedifferences are not constant
  • Tables: make sure x goes up by equal steps, then compare the change in y each time. Equal changes → linear.
  • Words: “$3 per ride” (no starting fee) is proportional; “$3 per ride plus a $10 fee” is linear but nonproportional.
  • The rate of change is the slope; the value at x = 0 is the initial value.

Worked example · classify a table

x: 0, 2, 4, 6 and y: 5, 11, 17, 23. Is it proportional, nonproportional linear or nonlinear?

  1. Changes in x: 2, 2, 2. Changes in y: 6, 6, 6.
  2. Rates: 6/2 = 3 every time → constant → linear.
  3. At x = 0, y = 5 (not 0) → not proportional.
Answer: Linear and nonproportional: y = 3x + 5.
Common mistakes
  • Calling a table linear when the x-values are not evenly spaced without dividing by Δx.
  • Thinking “linear” means “proportional”: only lines through the origin are proportional.
  • Subtracting in a different order for y and x: use y₂ − y₁ over x₂ − x₁ consistently.

3. Domain and range of functions

You should be able to… Decide if a relation is a function; find domain and range from graphs, tables, mappings and pairs; name the variables.

Key ideas

Relation
Any set of ordered pairs (x, y).
Function
A relation where every input has exactly one output.
Domain
All possible inputs (x-values, independent variable).
Range
All possible outputs (y-values, dependent variable).
  • Ordered pairs / tables / mappings: a function if no x-value is repeated with different y-values. List the domain (x’s) and range (y’s), each value once.
  • Graphs: use the vertical line test. Domain = how far left to right the graph goes; range = how far down to up.
  • Closed dot = value included (≤ or ≥); open dot = value excluded (< or >).
  • Context: the quantity that depends on the other is the dependent variable (output). Count-type inputs are usually discrete (whole numbers); measured quantities are continuous.

Worked example · function or not?

Is {(2, 5), (3, 7), (4, 5), (2, 9)} a function? Give the domain and range.

  1. The input 2 appears twice with outputs 5 and 9.
  2. So it is not a function.
  3. Domain = {2, 3, 4}; range = {5, 7, 9}.
Answer: Not a function; domain {2, 3, 4}, range {5, 7, 9}.
Common mistakes
  • Saying a relation is not a function because an output repeats (that is allowed).
  • Swapping domain and range.
  • Listing a repeated value twice in the domain or range.
  • Using ≤ instead of < (or the reverse) for open and closed endpoints.

4. Slope-intercept form

You should be able to… Write and graph y = mx + b from graphs, tables and words; interpret slope and initial value.

Key ideas

y = mx + bm = slope (rate of change) · b = y-intercept (initial value, the y when x = 0)
m = riserun = y₂ − y₁x₂ − x₁
Writing y = mx + b
From…Find mFind b
a graphpick two clear points: rise ÷ runwhere the line crosses the y-axis
a tableΔy ÷ Δxthe y at x = 0 (or step backwards)
words“per …” (rate)“starting / initial / fee” amount
  • To graph: plot (0, b), then use the slope: up/down m’s numerator, right m’s denominator.
  • Positive slope rises, negative falls, zero is horizontal, undefined is vertical.
  • Interpret: “For every 1 [x-unit], y changes by m [y-units]; when x is 0, y is b.”

Worked example · graph and interpret

Graph y = −(2/3)x + 4 and interpret the slope when x is hours and y is liters left.

  1. Plot (0, 4).
  2. Slope −2/3: go down 2, right 3 → (3, 2); again → (6, 0).
  3. Interpretation: the amount decreases by 2 liters every 3 hours, and starts at 4 liters.
Answer: Line through (0, 4), (3, 2), (6, 0).
Common mistakes
  • Reading the slope as run ÷ rise.
  • Dropping the negative sign of a falling line.
  • Using the first y-value of a table as b when the table does not start at x = 0.

5. Linear functions and function notation

You should be able to… Evaluate f(x); write linear functions from tables, graphs and descriptions; interpret them in context.

Key ideas

f(x) = mx + bf(x) is read “f of x”: the output for input x. It does not mean f times x
Reading function notation
NotationMeaning
f(3)replace x with 3 and compute the output
f(3) = 11the point (3, 11) is on the graph
f(x) = 11solve for the input that gives 11
f(0)the initial value (y-intercept)
  • Writing f(x): find the slope m (Δoutput ÷ Δinput) and the initial value b, then write f(x) = mx + b.
  • Context: say what the input and output are, with units: “f(10) = 75 means after 10 weeks the value is 75.”
  • The independent variable can have any letter (f(d), P(w), C(t)).

Worked example · write and use a function

A taxi charges $3 plus $2 per mile. Write C(m), find C(10), and find the distance for a $31 fare.

  1. Rate $2 per mile, initial $3: C(m) = 2m + 3.
  2. C(10) = 2(10) + 3 = 23 → a 10-mile trip costs $23.
  3. Solve 2m + 3 = 31: 2m = 28, m = 14 miles.
Answer: C(m) = 2m + 3; C(10) = 23; 14 miles.
Common mistakes
  • Multiplying instead of substituting: f(3) is not f·3.
  • Mixing up f(a) = b: the input is a, the output is b.
  • Forgetting parentheses when substituting a negative: g(−3) = −2(−3) + 9.

6. Point-slope form

You should be able to… Write and graph y − y₁ = m(x − x₁) and convert it to slope-intercept form.

Key ideas

y − y₁ = m(x − x₁)m = slope · (x₁, y₁) = any point on the line
  • Use it when you know a point and the slope, or two points (find m first, then use either point).
  • Watch the signs: for the point (−1, 4) write y − 4 = m(x + 1), since x − (−1) = x + 1.
  • Graph: plot (x₁, y₁), then move by the slope.
  • Convert to y = mx + b: distribute m, then add y₁ to both sides.

Worked example · two points to slope-intercept

Write the line through (2, 3) and (6, 11) in point-slope and slope-intercept form.

  1. Slope: m = (11 − 3)/(6 − 2) = 8/4 = 2.
  2. Point-slope using (2, 3): y − 3 = 2(x − 2).
  3. Distribute: y − 3 = 2x − 4.
  4. Add 3: y = 2x − 1.
  5. Check with the other point: 2(6) − 1 = 11 ✓.
Answer: y − 3 = 2(x − 2), or y = 2x − 1
Common mistakes
  • Putting the coordinates in the wrong places (y₁ goes with y, x₁ with x).
  • Keeping the sign of the point instead of subtracting it.
  • Adding y₁ to only one side when converting.

Worked example · all three forms

Write the line through (0, 4) and (6, 0) in slope-intercept, point-slope (using (6, 0)) and standard form.

  1. Slope = (0 − 4)/(6 − 0) = −2/3; y-intercept 4. Slope-intercept: y = −(2/3)x + 4.
  2. Point-slope with (6, 0): y − 0 = −(2/3)(x − 6).
  3. Standard: multiply y = −(2/3)x + 4 by 3 → 3y = −2x + 12 → 2x + 3y = 12.
Answer: y = −(2/3)x + 4 · y = −(2/3)(x − 6) · 2x + 3y = 12
Common mistakes
  • Leaving fractions in A, B or C, or a negative A.
  • Forgetting to divide every term when isolating y (especially when dividing by a negative).
  • Mixing up the intercepts: the x-intercept comes from y = 0.

8. Parallel and perpendicular lines

You should be able to… Classify lines by slope; write parallel and perpendicular lines through a point; verify on a graph.

Key ideas

Classify by slope
RelationshipSlopesIntercepts
Parallelequal: m₁ = m₂different
Same (coincident) lineequalequal
Perpendicularnegative reciprocals: m₁ · m₂ = −1any
Neitheranything else
  • Write both equations in slope-intercept form first (solve for y).
  • Negative reciprocal: flip the fraction and change the sign: 2/3 → −3/2; −5 → 1/5.
  • A horizontal line (slope 0) is perpendicular to a vertical line (undefined slope).
  • Writing a parallel / perpendicular line through a point: (1) find the needed slope, (2) use point-slope with the given point, (3) simplify.
  • Verify on a graph: parallel lines never meet; perpendicular lines meet at a right angle.

Worked example · perpendicular through a point

Write the line perpendicular to y = (2/3)x + 1 through (6, −1).

  1. Perpendicular slope: negative reciprocal of 2/3 is −3/2.
  2. Point-slope: y + 1 = −(3/2)(x − 6).
  3. Distribute: y + 1 = −(3/2)x + 9.
  4. Subtract 1: y = −(3/2)x + 8.
Answer: y = −(3/2)x + 8
Common mistakes
  • Only flipping the fraction (forgetting the sign change) or only changing the sign.
  • Comparing slopes of equations that are not yet solved for y (2x + 3y = 6 does not have slope 2).
  • Using the original point’s coordinates incorrectly in point-slope form.

9. Arithmetic sequences

You should be able to… Find d and missing terms; write explicit (aₙ = a₁ + (n − 1)d) and recursive formulas; connect them to linear functions.

Key ideas

d = aₙ − aₙ₋₁ · aₙ = a₁ + (n − 1)dd = common difference (constant change). Explicit formula: jump straight to any term
a₁ = (first term), aₙ = aₙ₋₁ + dRecursive formula: each term comes from the previous one
  • Find d: subtract consecutive terms, or from two terms: d = (aₘ − aₖ)/(m − k).
  • Missing terms: find d, then add it step by step.
  • Connection to linear functions: aₙ = dn + (a₁ − d) is a linear function of n with slope d. The domain is the positive whole numbers (the graph is dots, not a line).
  • Not arithmetic: if the ratio between terms is constant (2, 4, 8, …) the sequence is geometric.

Worked example · explicit and recursive

Write the explicit and recursive formulas for 20, 17, 14, 11, … and find a₁₅.

  1. d = 17 − 20 = −3; a₁ = 20.
  2. Explicit: aₙ = 20 + (n − 1)(−3) = −3n + 23.
  3. Recursive: a₁ = 20, aₙ = aₙ₋₁ − 3.
  4. a₁₅ = −3(15) + 23 = −22.
Answer: aₙ = −3n + 23; a₁ = 20, aₙ = aₙ₋₁ − 3; a₁₅ = −22
Common mistakes
  • Using n instead of (n − 1) in the formula (a₁ would then be wrong).
  • Counting terms instead of steps: from a₅ to a₉ there are 4 steps, not 5.
  • Forgetting the sign of a negative d.

10. Solving systems by graphing

You should be able to… Find the intersection; classify one, no or infinitely many solutions; interpret the solution.

Key ideas

A system of linear equations is two (or more) equations with the same variables. A solution is an ordered pair (x, y) that makes both equations true: the point where the graphs meet.

Classifying a system
GraphsSlopes / interceptsSolutions
cross oncedifferent slopesone solution (x, y)
parallelsame slope, different interceptsno solution
same linesame slope, same interceptinfinitely many
  1. Write each equation in slope-intercept form.
  2. Graph both lines (plot b, then use the slope).
  3. Read the intersection point.
  4. Check it in both original equations.
  5. Interpret it in context (for example, the break-even point).

Try it

Worked example · break-even

Plan A costs y = 15x + 50, plan B costs y = 25x + 10 (x months). Find and interpret the solution.

  1. Graph both lines: A starts at 50 rising 15 per month; B starts at 10 rising 25 per month.
  2. They meet at (4, 110).
  3. Check: 15(4) + 50 = 110 ✓ and 25(4) + 10 = 110 ✓.
Answer: (4, 110): after 4 months both plans have cost $110 in total; after that plan B is more expensive.
Common mistakes
  • Reading an approximate intersection from a sloppy graph: always check in both equations.
  • Saying “no solution” when the lines merely look close but have different slopes.
  • Forgetting that infinitely many solutions means the equations describe the same line.

11. Solving systems by substitution

You should be able to… Isolate a variable, substitute, solve, and check the ordered pair.

Key ideas

  1. Isolate one variable in one equation (choose a variable with coefficient 1 or −1 if you can).
  2. Substitute that expression into the other equation (use parentheses!).
  3. Solve the resulting one-variable equation.
  4. Back-substitute to find the other variable.
  5. Check the pair in both original equations.
Special cases
Result of substitutingMeaning
x = 3 (a number)one solution; find y
false statement (2 = 5)no solution
true statement (−6 = −6)infinitely many solutions

Worked example · substitution

Solve y = 2x − 3 and 4x + y = 9.

  1. y is already isolated: replace y in the second equation.
  2. 4x + (2x − 3) = 9 → 6x − 3 = 9 → 6x = 12 → x = 2.
  3. y = 2(2) − 3 = 1.
  4. Check: 4(2) + 1 = 9 ✓ and 1 = 2(2) − 3 ✓.
Answer: (2, 1)
Common mistakes
  • Substituting back into the same equation you solved (you get a true statement and no information).
  • Forgetting parentheses: x − (10 − 2x) is x − 10 + 2x, not x − 10 − 2x.
  • Finding x and stopping: the solution is an ordered pair (x, y).

12. Solving systems by elimination

You should be able to… Add, subtract or multiply to eliminate; choose the most efficient method.

Key ideas

  1. Write both equations in standard form, variables lined up (Ax + By = C).
  2. Make the coefficients of one variable opposites: multiply one or both equations by numbers if needed.
  3. Add the equations (or subtract if the coefficients are equal) to eliminate that variable.
  4. Solve for the remaining variable, then back-substitute.
  5. Check in both original equations.
Choosing the most efficient method
SituationBest method
one variable already isolated (y = …)substitution
a coefficient of 1 or −1 you can isolate easilysubstitution
both equations in standard formelimination
coefficients already equal or oppositeelimination (add/subtract at once)
you want a visual picture or an estimategraphing

Worked example · multiply first

Solve 3x + 2y = 7 and 5x − 4y = −3.

  1. Multiply the first equation by 2: 6x + 4y = 14.
  2. Add to the second equation: 11x = 11 → x = 1.
  3. Back-substitute: 3(1) + 2y = 7 → y = 2.
  4. Check: 5(1) − 4(2) = −3 ✓.
Answer: (1, 2)
Common mistakes
  • Multiplying only one side of an equation (multiply every term, including the right side).
  • Sign errors when subtracting: subtracting −3 adds 3.
  • Eliminating a variable but forgetting to find the other one.
