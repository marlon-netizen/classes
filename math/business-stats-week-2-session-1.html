  • Bar chart: one bar per category; bars separated; length = frequency. Sort by size unless categories have a natural order.
  • Pareto chart: bars sorted from largest to smallest plus a cumulative-percentage line. It shows the “vital few” causes (e.g. complaint types).
  • Pie chart: only for a few parts of a whole; label the percentages.
  • Two categorical variables: a contingency (cross-)table, or a clustered / stacked bar chart (Week 3 uses these tables for probability).

Organising numerical data: frequency distributions

A numerical variable with many different values is grouped into classes (intervals) that do not overlap and cover every value.

  1. Find the range = largest − smallest.
  2. Choose the number of classes k, typically 5 to 15. Sturges’ rule: k ≈ 1 + 3.322 log₁₀ n.
  3. Class width ≈ range / k, rounded up to a convenient number.
  4. Set class limits starting at or below the minimum. Use “lower limit up to but not including upper limit” so no value fits two classes.
  5. Tally the data, then compute frequency, relative frequency and cumulative frequency.

Worked example · building a frequency distribution

A warehouse recorded the number of orders shipped on each of 40 days (minimum 25, maximum 56). Organise the data.

  1. Range = 56 − 25 = 31.
  2. Sturges: k ≈ 1 + 3.322 log₁₀(40) = 6.32 → about 7 classes.
  3. Width ≈ 31/7 = 4.43 → use 5 (a convenient number), starting at 25.
  4. Classes: 25–under 30, 30–under 35, …, 55–under 60 (7 classes cover 25 to 60).
  5. Tally and count; check that the frequencies add to 40.

Describing a distribution

Four things to say about any distribution
FeatureQuestionsVocabulary
CentreWhere is the typical value?around 40 units
SpreadHow variable are the values?narrow, wide, range
ShapeSymmetric? Skewed? How many peaks?symmetric · right-skewed · left-skewed · unimodal · bimodal · uniform
Unusual featuresGaps, outliers, clusterspossible data errors or special cases
  • Right-skewed (positive): long tail to the right (incomes, order values, waiting times). Mean > median.
  • Left-skewed (negative): long tail to the left (exam marks near the maximum, age at retirement). Mean < median.
  • Symmetric: mirror image; mean ≈ median.
  • Bimodal: two peaks, often two different groups mixed (e.g. business and personal customers).
Bin width changes the story

Too few classes hide features such as a second peak; too many make random noise look like structure. Always try two or three widths before drawing conclusions.

Scatter plots and time series

A scatter plot shows two numerical variables for the same cases: one point per case. Put the explanatory variable (what you think influences) on the x-axis and the response on the y-axis.

Reading a scatter plot
Describe…Examples
Directionpositive (up together), negative (one up, other down), none
Formlinear, curved, clusters
Strengthtight band = strong, wide cloud = weak
Unusual pointsoutliers that do not follow the pattern; influential points
  • Example: advertising spend (x) vs sales (y): positive, roughly linear.
  • Example: price (x) vs units sold (y): negative.
  • Time series: a line chart with time on the x-axis shows trend, seasonality and sudden changes.
Association is not causation

A strong pattern can come from a lurking variable (temperature drives both ice-cream and sunscreen sales) or from chance. Only a well-designed experiment supports a causal claim. Numerical measures of association (correlation) are not part of these first six weeks, so describe the pattern in words.

Principles of honest graphs
  • Bars start at zero; do not truncate bar-chart axes.
  • Title says the “so what”, axes have labels and units.
  • No 3-D, no decoration, no dual axes that mislead.
  • Use colour sparingly and make it colour-blind safe.
  • Show the sample size or source.

Watch the bin rule

Excel’s Histogram chart uses bins of the form (a, b] (upper limit included) by default, while many textbooks use [a, b). A value exactly on a boundary can land in different classes. State which rule you used.

Common mistakes

  • Overlapping classes (10–20, 20–30) so a value of 20 fits twice.
  • Unequal class widths without adjusting heights.
  • Using a bar chart (gaps) for numerical data, or a histogram for categories.
  • Reading a histogram’s height as “value” instead of “frequency”.
  • Letting software choose bins without looking at the result.
  • Truncated axes, 3-D effects, and too many pie slices.
