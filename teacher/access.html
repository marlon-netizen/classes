Which lessons does each grade & class see? Tick a box to show that lesson to every student whose Grade and Class match the row (as typed in Students & codes; a student whose Class lists several subjects separated by “/” is in each of those rows). A lesson shows everyone until you un-tick a box for it; after that only the ticked rows see it. Students never see lessons that are not theirs, and cannot open them from a link either. Changes apply the next time the student opens a page.
